# Custom Audio Player (Vanilla JS)

Кастомный музыкальный веб-плеер с интерактивной перемоткой, управлением громкостью и плейлистом, загружающим треки по прямым ссылкам (URL). Проект создан для практики работы с HTML5 Media API и DOM-событиями без использования сторонних библиотек и фреймворков.

## Стек и ограничения

* **Технологии:** Семантический HTML5, чистый CSS (Flexbox/Grid, CSS-переменные), Vanilla JavaScript (ES6+).
* **Окружение:** Десктопная версия (от 1280px), без мобильной адаптации.
* **Движок:** Скрытый нативный тег `<audio>`, управляемый через кастомный интерфейс.

## Отрабатываемые темы JS

* **HTML5 Media API:** методы `play()`, `pause()`, свойства `src`, `currentTime`, `duration`, `volume`, `muted`.
* **Медиа- и сетевые события:** `loadedmetadata`, `timeupdate`, `ended`, `waiting`, `canplay`, `error`.
* **Геометрия и координаты:** расчет позиции клика мыши с помощью `getBoundingClientRect()` и `clientX`.

## Схема данных трека

Каждый элемент в массиве плейлиста описывается объектом со следующей структурой:

* `id` — уникальный идентификатор трека (число или строка).
* `title` — название композиции.
* `artist` — имя исполнителя.
* `audioUrl` — прямая ссылка на аудиофайл (`.mp3`, `.ogg`, `.wav`).
* `coverUrl` — ссылка на обложку альбома или локальный путь к изображению.

## Функциональные требования (MVP)

### Воспроизведение и навигация
- [ ] Запуск и пауза трека по клику на кнопку **Play / Pause** с изменением иконки.
- [ ] Переключение треков по кругу кнопками **«Назад»** и **«Вперед»**.
- [ ] Выбор и мгновенный запуск любого трека при клике на строку в плейлисте.
- [ ] Автоматический переход к следующему треку по окончании текущего (событие `ended`).

### Прогресс-бар и перемотка
- [ ] Отображение общей длительности трека в формате `ММ:СС` после загрузки метаданных (`loadedmetadata`).
- [ ] Плавное заполнение полосы прогресса и обновление таймера в реальном времени (`timeupdate`).
- [ ] Перемотка трека на нужную секунду при клике в любое место полосы прогресса.

### Управление звуком
- [ ] Изменение уровня громкости кликом по шкале звука (`volume` от `0` до `1`).
- [ ] Включение и выключение беззвучного режима по кнопке **Mute** (`muted`) с сохранением предыдущего уровня громкости.

## Обработка крайних случаев (Edge Cases)

- [ ] **Защита от `NaN`:** до загрузки метаданных таймер показывает `00:00`, а перемотка по шкале заблокирована.
- [ ] **Форматирование времени:** числа меньше 10 всегда отображаются с ведущим нулем (например, `01:05`, а не `1:5`).
- [ ] **Индикация загрузки:** визуальный отклик интерфейса при буферизации потока по сети (`waiting` / `canplay`).
- [ ] **Обработка ошибок:** вывод понятного уведомления пользователю, если ссылка на аудиофайл недоступна (`error`).
