# Roadmap: Frontend Refresh (Vanilla JS)

Этот репозиторий содержит пошаговый трек из 10 пет-проектов для уверенного освоения чистого JavaScript. Список составлен по принципу плавного усложнения: от работы с таймерами и DOM до асинхронных API, структур данных и архитектурных паттернов.

---

## 📋 Список проектов

### Блок 1: UI, события и таймеры
*   [x] **01. Доработка кликера: Магазин улучшений**
    *   *Суть:* Превращение базового кликера в экономическую игру с автоматическим начислением очков через таймеры.
    *   *Ключевые темы:* `setInterval`, `clearInterval`, валидация баланса, обновление текстовых узлов.
*   [ ] **02. Кастомный медиаплеер**
    *   *Суть:* Плеер для музыки или видео с полностью самодельными кнопками управления и интерактивной полосой прогресса.
    *   *Ключевые темы:* HTML5 Media API, события `timeupdate` и `ended`, расчет координат клика мыши.
*   [ ] **03. Таймер Pomodoro со звуком**
    *   *Суть:* Счетчик рабочих сессий и отдыха с кастомной настройкой времени и звуковыми уведомлениями.
    *   *Ключевые темы:* `Audio API`, синхронизация таймеров, кастомный progress bar.
*   [ ] **04. Переиспользуемый Dropdown**
    *   *Суть:* Скрипт, превращающий обычные теги `div` в доступные селекторы с поддержкой управления с клавиатуры.
    *   *Ключевые темы:* События клавиатуры (`keydown`), фокус, кастомные HTML-атрибуты.

### Блок 2: Асинхронность и интеграция с API
*   [ ] **05. Виджет погоды**
    *   *Суть:* Форма поиска прогноза погоды для разных городов с динамической генерацией карточек на лету.
    *   *Ключевые темы:* `fetch`, асинхронный код (`async/await`), обработка ошибок `try/catch`.
*   [ ] **06. Конвертер валют с графиком**
    *   *Суть:* Расчет актуальных курсов валют из открытого API с отрисовкой истории изменений за неделю.
    *   *Ключевые темы:* Работа с несколькими асинхронными потоками, тег `<canvas>` или легкие библиотеки графиков.
*   [ ] **07. Поисковик фильмов с «Избранным»**
    *   *Суть:* Каталог фильмов с поиском, детальными описаниями и добавлением в локальные закладки.
    *   *Ключевые темы:* Методы массивов (`filter`, `map`, `find`), коллекция `Set` для исключения дубликатов, `localStorage`.

### Блок 3: Алгоритмы, структуры данных и architecture
*   [ ] **08. Визуализатор обхода графа / лабиринта**
    *   *Суть:* Пошаговое интерактивное отображение работы алгоритма (поиск циклов, путей или тупиков) на координатной сетке.
    *   *Ключевые темы:* Матрицы, списки смежности, создание контролируемой задержки кадров через `Promise` и `setTimeout`.
*   [ ] **09. Канбан-доска (Trello-style)**
    *   *Суть:* Инструмент управления задачами с колонками, генерацией карточек и их перетаскиванием.
    *   *Ключевые темы:* HTML5 Drag and Drop API, генерация уникальных идентификаторов (`crypto.randomUUID()`), хранение связей объектов.
*   [ ] **10. Модульное SPA-приложение**
    *   *Суть:* Интернет-магазин с каталогом и корзиной, переключающий страницы без перезагрузки браузера.
    *   *Ключевые темы:* Модули в JS (`import/export`), кастомный роутинг через `History API` или событие `hashchange`.

---

## 🛠️ Правила разработки

1. **Только Vanilla JS:** Никаких сторонних UI-фреймворков или библиотек (React, Vue, jQuery). Всё пишется на чистом языке.
2. **Осознанный код:** Полный отказ от слепого копирования готовых решений. Важно понимать логику каждого написанного метода и структуры.
3. **Раздельные коммиты:** Решения задач и документация коммитятся отдельно для поддержания чистоты истории репозитория.
