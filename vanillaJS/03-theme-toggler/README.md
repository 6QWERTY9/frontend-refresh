
# Техническое задание: Переключатель темы «День/Ночь» с параллаксом


## 1. Суть компонента

Интерактивная кнопка-переключатель для смены оформления сайта между светлой и темной темами. Кнопка представляет собой прямоугольное основание (капсулу), внутри которого перемещается бегунок, а на фоне меняется окружение.

## 2. Логика работы анимации (Параллакс)

Вся анимация запускается в момент клика по кнопке. Чтобы создать ощущение глубины и объема, три независимых слоя двигаются одновременно, но с разной скоростью:

• **Передний план (Бегунок-трансформер):**
	• Двигается быстрее всех слева направо.
	• В левом положении он выглядит как круглое желтое солнце с ярким свечением.
	• В процессе движения направо он плавно трансформируется: его тело становится прозрачным, а сбоку прорисовывается светлый полумесяц.
• **Средний план (Дневные облака):**
	• Находятся на фоне, пока включена светлая тема.
	• При переключении на темную тему они уплывают в левую сторону с умеренной скоростью и полностью исчезают.
• **Задний план (Ночные звезды):**
	• Изначально скрыты за правым краем кнопки.
	• При включении ночного режима они лениво и медленно выплывают справа налево, занимая ночное небо. За счет того, что они движутся медленнее бегунка и облаков, создается эффект трехмерного пространства.

## 3. Логика кода и сохранение выбора

• **Стек:** Чистый HTML, CSS и JavaScript. В скриптах не используются классы, только лаконичный процедурный код.

• **Сохранение темы:** Выбор пользователя должен автоматически записываться в память браузера (LocalStorage).

• **Проверка при входе:** При обновлении или повторном открытии страницы скрипт должен мгновенно проверять, какая тема была выбрана ранее. Если пользователь оставил темную тему, кнопка сразу должна отображаться в состоянии «ночь», а сайт — перекрашиваться в темные тона без резких миганий.
